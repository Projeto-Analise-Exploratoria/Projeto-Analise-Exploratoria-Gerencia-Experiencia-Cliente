## 📌 Sobre o projeto

Trabalho da disciplina de Ciência de Dados utilizando a base da Olist, com foco na Gerência de Experiência do Cliente.

O objetivo é analisar as avaliações dos clientes, identificar os fatores relacionados às notas baixas, verificar a influência dos atrasos nas entregas e entender quais problemas merecem mais atenção.

O projeto envolve limpeza, tratamento e transformação dos dados, análise exploratória e apresentação dos resultados em um painel no Streamlit.

## 🛠️ Etapas desenvolvidas

###  Frente 1 — Limpeza e tratamento dos dados

Foram realizadas a leitura das bases, verificação de valores nulos, duplicatas, conversão de tipos, tratamento de datas e identificação de outliers.

**Arquivos:**
- `LimpaTrabalhoFinal.ipynb`
- 5 arquivos CSV tratados.

###  Frente 2 — Transformações e Feature Engineering

Foram realizadas a junção das tabelas, criação de novos atributos, codificação de dados categóricos, normalização MinMax, padronização Z-score e seleção de atributos.

**Arquivos:**
- `Frente2_Olist_Experiencia_Cliente.ipynb`
- `tabela_analitica_frente2.csv`
- `selecao_atributos_frente2.csv`
- `dicionario_colunas_frente2.csv`
